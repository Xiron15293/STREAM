# STREAM — MVP Roadmap

> Percorso verso la versione minima distribuibile pubblicamente.

## Criteri MVP

L'MVP è raggiunto quando un utente può:
1. Inserire movimenti (entrate/uscite) ✅ (V0.1)
2. Vederli in dashboard ✅ (V0.1)
3. Modificarli ed eliminarli ✅ (V0.3)
4. Organizzarli per categorie personalizzabili ✅ (V0.3)
5. Non perderli alla chiusura dell'app ✅ (V0.3 — SQLite)
6. Usare conti separati ✅ (V0.3)
7. Inserire movimenti velocemente ✅ (V0.2)
